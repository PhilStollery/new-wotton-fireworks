WHAT THIS FIXES
---------------
V26 changed the presentation scheduler to queueMicrotask while a MutationObserver watched the page. Because the presentation code itself changes the DOM, it could immediately trigger itself again and starve the browser, making the page appear frozen.

V27 returns presentation updates to requestAnimationFrame and disconnects the observer while the presentation pass changes its own DOM.
