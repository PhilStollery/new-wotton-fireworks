# Wotton Fireworks 2026 integration v25

V25 is cumulative over v24.

- Standard availability now follows the remaining `# Event Capacity`, so complimentary and pre-school admissions reduce Standard capacity naturally.
- `Release 2 - Advance` is recognised directly.
- Parking uses the single 150-space `# Parking Capacity` Activity for paid and Blue Badge parking.
- Price comparison puts Pre-school above the paid age bands and shows parking in its own compact table.
- The Tito selector is presented in the same dark visual language as the rest of the ticket flow.
- Automatic spillover updates both the visible controls and Tito's underlying selector state so Continue is re-evaluated after corrections.
- Old under-16 accompaniment wording is stripped from ticket descriptions in the browser pending Tito-description cleanup.
- Blue Badge display wording is kept inside the Blue Badge ticket description.
