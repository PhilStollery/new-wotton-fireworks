# Integration notes — v26

V26 is a presentation/selection-state patch over v25.

## Counter rendering

The original selector code can briefly rewrite group-counter HTML after a quantity change. V26 hides unclassified legacy counter children and gives the v26 title/status children explicit classes. The presentation patch is scheduled as a microtask rather than waiting for the next animation frame, preventing obsolete copy from becoming visible between states.

## Automatic corrections

Where a browser selection is automatically moved/reduced to stay within a Tito Activity or the overall event capacity, the notice now requires an explicit **OK** acknowledgement. Non-correction informational messages may still time out normally.

## Event capacity

Browser-side admission totals now include the Pre-school quantity as well as all paid waves. This mirrors the Tito setup where Pre-school and other attendance releases count against `# Event Capacity`.

## FAQ / lower-page presentation

- FAQ kicker: `FAQ`.
- FAQ disclosures use left-hand white triangles and one rounded outer panel.
- Tickets → Plan your visit spacing is reduced.
- The final update/contact section is restored to the full-width yellow treatment.
